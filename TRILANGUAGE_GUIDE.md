# TEMPO GROUP — UZ / RU / EN (Vue 3)

This is the Tempo brandbook-integrated multi-page Vue 3 site with three fully localized languages. The application has no additional runtime i18n dependency. Playwright is a development dependency for browser tests. The site uses a tiny reactive language store built with Vue's `ref`/`computed` to avoid modifying your current dependencies.

## Run

```bash
npm install
npm run dev
npm run build
```

## Included

- Switchers in desktop header, mobile menu and footer: UZ / RU / EN.
- Localized: hero, intro / preloader, navbar, products (9 products, names and descriptions), filters, details modal, about, advantages, process, catalogue preview, contact page, order page, form validation/success messages, footer, meta title/description, map labels.
- All product selection values use stable **IDs**; switching language never loses the selected product.
- Persists language in `localStorage` under `tempo-preferred-language`; defaults to `uz`.
- Sets `<html lang>` and title/description when route or language changes.
- The existing routes stay: `/`, `/mahsulotlar`, `/boglanish`, `/buyurtma` (unchanged across languages).
- `IntroPipeTunnel.vue` shows the correct language for slogan and skip button; displays once per session as before.
- Official Tempo logos and official brandbook colors stay the same.

## Where to edit

- `src/i18n/messages.js` — all text translations for UZ / RU / EN. Do not rename keys.
- `src/i18n/index.js` — reactive `locale`, `setLocale`, `t`, localized products/categories/advantages.
- `src/components/LanguageSwitcher.vue` — language control.
- `src/styles-i18n.css` — styling (responsive header/menu/footer).
- `src/data/site.js` — phone, website, product IDs and images, default site data, sample address.

**Important:** Address is a *sample*, not a verified factory location. Update `location.address` and `location.query` in **all three** language objects in `src/i18n/messages.js` when the real address is known, and update `site.js` for the raw Uzbek default. Phone is from the supplied Tempo product catalogue.

Order form is in demo mode (`formEndpoint: ''` in `src/data/site.js`). It prepares copyable text rather than claiming that an order was sent. If you enable a backend, API payload includes the localized `product` name and stable `productId`.

The Tempo 2024 brandbook names Axiforma / Helvetica Neue typography. Axiforma font files are *not* redistributed in this project; the CSS falls back to installed fonts.

## QA checklist

1. Enter home on UZ, click RU then EN; confirm header, hero, cards, footer all change.
2. Open product detail, switch language via header (desktop) and confirm text changes (modal is a teleport).
3. Choose a product and click enquiry. On the order page product is preselected, even after changing languages.
4. Validate form with missing fields in each language. Copy prepared enquiry text and ensure correct translated labels.
5. Use contact link, verify the map and sample address labels in each language.
6. Test mobile hamburger menu, the language control, page navigation.
7. Reload and check language is remembered. Start a new browser session and confirm the Pipe Tunnel intro still works.
8. Run `npm run build` on your own machine and fix issues in your actual combined repository.

## Automated checks

- `npm run test:i18n`: complete key/array parity, blank values, interpolation, static template strings, switching and storage.
- `npm run test:i18n:browser`: starts its own Vite server and checks all four routes at 1440px and 390px in UZ/RU/EN, forms, modals, persistence and page titles. On Windows it uses installed Microsoft Edge; elsewhere run `npx playwright install chromium` first.
- `npm run build`: automatically regenerates the six localized SVG catalogue overlays before building.

Catalogue text overlays are generated by `scripts/generate-catalog.mjs` from `src/i18n/messages.js`; original raster artwork remains embedded to preserve photography and technical tables.

Verified locally: production build, translation checks and desktop/mobile browser tests.
